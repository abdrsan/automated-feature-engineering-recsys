# Текст для сдачи

Здравствуйте!

Направляю решение задания «Сравнить методы Feature Engineering».

Репозиторий: https://github.com/abdrsan/automated-feature-engineering-recsys

Основной отчет и исполняемый код находятся в `FINAL_SUBMISSION/feature_engineering_comparison.ipynb`.
В работе на данных KION и Yambda сравниваются базовые признаки, ручные временные
агрегаты, multi-scale trends, автоматическая генерация и отбор признаков.
Сравнение выполнено с общей моделью LightGBM, одинаковым временным разбиением и
общими параметрами внутри каждого датасета. Приведены реальные метрики,
вычислительная стоимость, анализ признаков и ограничения результатов.

В README описаны запуск, источники данных и воспроизведение экспериментов.
Первая ячейка notebook проверяет и при необходимости устанавливает зависимости.
Для быстрой проверки предусмотрен demo-режим; полные результаты показаны отдельно.
Подробный исходный pipeline, тесты и дополнительное исследование также включены в репозиторий.
